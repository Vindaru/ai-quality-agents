  This injection was not in a language the input filter covers. The reply was harmless only because the model did not act on it, which is luck, not a control. Next step: multilingual injection detection.

## Known limitations

- **Small golden sets** (14 stories, 48 failures, 28 safety prompts). Look at the triage confidence interval before reading much into a 2-point change.
- **Mock model.** These numbers come from a deterministic heuristic mock so CI is free and repeatable. Its mistakes are real outputs of that mock, but a real model will make different ones. Set `AIQ_LLM_PROVIDER=anthropic` to measure a real model.
- **Keyword matching for expected scenarios.** A correct scenario worded differently counts as a miss. An LLM-as-judge, calibrated against human labels, is the planned upgrade.
- **Regex PHI detection** over-redacts (for example ISO dates in logs) and cannot see free-text PHI such as diagnoses or names. It is a backstop, not a de-identification service.
- **Injection detection is pattern based** and covers English and Spanish only.
- **Thresholds were set from the first baseline run** and should be tightened as the agents improve.
